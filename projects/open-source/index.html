I've been contributing to Babashka and SCI, the Small Clojure Interpreter behind it, since 2020.

  • SCI: a copy-vars regression (2026). I wrote failing tests that exposed copy-vars incorrectly marking functions as inlined, then fixed the regression, including the cljs.core and fast-path cases.
  • Babashka: issue reproduction (2026). I added bb tasks that reproduce issue #1979 side by side against an earlier release, to make the regression easy to bisect.
  • Babashka: JVM class additions (2021–2023). I added IllegalStateException, InterruptedException and javax.crypto.spec.IvParameterSpec to the native image. The last one made Ansible Vault decryption possible in a bb script.
  • Babashka: examples (2020–2022). I contributed a single-page app with Babashka and htmx, a DigitalOcean utility, and a write-up on exporting from passwordstore.

Contributing to a GraalVM-compiled interpreter means thinking about what gets baked into the binary, and why. That's a very different mindset from application code.
