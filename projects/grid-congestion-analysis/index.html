Grid congestion analysis

2026 · An interactive data dashboard visualizing Dutch electricity network bottlenecks and future congestion.

  • D3.js
  • Python
  • GeoJSON
  • Data Visualization

Live

This project visualizes data about congestion points in the Dutch electricity network, showing both current hotspots and projections for future bottlenecks as the country transitions to renewable energy.

The dashboard

The interactive dashboard maps nearly 1,000 congestion points across the country, colorized by severity and category. You can explore which regions are expected to face the most stress as generation patterns shift.

Why this matters

Grid planners and policymakers need to know where to invest in new infrastructure. This dashboard makes that data navigable and explorable, turning raw datasets into spatial patterns you can reason about.

What I built

  • Cleaned and standardized multiple government data sources into a unified GeoJSON format
  • Built an interactive D3.js visualization with filtering, tooltips and temporal controls
  • Automated the data pipeline with Python to handle updates and new projections
