Thorgend

2026 · A Rust synthesizer plugin built on Xenakis's GENDY dynamic stochastic synthesis.

  • Rust
  • nih-plug
  • Audio DSP
  • VST3 / CLAP / AU

View on GitHub

Most synthesizers start from a fixed waveform and filter it. Iannis Xenakis's dynamic stochastic synthesis (GENDY) does something else. Each cycle, the waveform is a polygon of breakpoints, and every breakpoint takes a random walk in time and amplitude. The sound is never quite the same twice.

Thorgend is an instrument plugin built around that idea. It compiles to VST3, CLAP and AUv2 from one Rust codebase using nih-plug.

The interesting parts

  • A standalone DSP crate. The GENDY oscillator, ADSR envelope and LFO live in their own crate, separate from the plugin glue, and they're unit-tested without a host.
  • Pitch-drift compensation. Random walks in segment duration make the pitch wander by nature. Thorgend corrects for this, so a played note stays in tune while the timbre keeps moving.
  • Polyphony and voice stacking. Several voices can sing the same note, each with its own random path, which thickens the sound into a chorus.
  • Musical controls. The raw stochastic parameters are mapped onto a handful of controls a player can reason about: richness, noise complexity, rate and saturation.

What I learned

Real-time audio is unforgiving. There's no allocating, no locking and no surprises inside the audio callback. Rust's ownership model made that discipline feel like a feature rather than a chore.
