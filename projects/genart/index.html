Generative art

2024–2026 · Interactive generative sketches in Quil, built on my own genartgear library.

  • Clojure
  • Quil
  • Processing

View on GitHub

A REPL-driven sketchbook. Each sketch is a small Quil program that I reshape live from the editor: layered noise fields, 3D layers, masks, line studies and pentagon tilings.

The reusable pieces, like layering, masking and noise helpers, live in genartgear, a small library I published to Clojars so new sketches start from a palette of tools rather than a blank canvas.
